# SentinAI Overview

SentinAI is an AI-powered Anti-Money Laundering (AML) compliance system designed for Kenyan mobile money platforms, specifically M-Pesa. The system ingests mobile transaction data, processes it through a multi-layered AI pipeline, and generates Suspicious Activity Reports (SARs) aligned with CBK Prudential Guidelines.

## Key Capabilities
- Real-time mobile money transaction monitoring
- AI-driven anomaly detection across temporal, value, and network dimensions
- Automated SAR generation compliant with CBK regulations
- Dashboard for compliance officer review

## Regulatory Context
- Central Bank of Kenya (CBK) Prudential Guidelines
- Anti-Money Laundering & Counter Financing of Terrorism (AML/CFT) requirements
- Suspicious Activity Report (SAR) filing mandates
